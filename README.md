# EditoLina

**EditoLina is an independent community project and a fork of [PhotoCraft](https://github.com/storytold/photocraft), the open-source image editor created by the ArtCraft team and its contributors.**

This repository starts from PhotoCraft's codebase. We are grateful to the original developers and contributors, and we preserve the upstream license terms, copyright notices, and third-party attributions. See [`NOTICE`](NOTICE), [`ATTRIBUTION.md`](ATTRIBUTION.md), [`LICENSE-MIT`](LICENSE-MIT), and [`LICENSE-APACHE`](LICENSE-APACHE).

## A distinct direction

EditoLina aims to grow with its own identity, priorities, and community. The current codebase still contains inherited PhotoCraft implementation and project naming; features already present in the fork are not necessarily new EditoLina work. We will identify and describe original changes as they are made, without obscuring their upstream origins.

EditoLina is not affiliated with, sponsored by, or endorsed by the PhotoCraft or ArtCraft teams. Their names and marks belong to their respective owners. This project uses the PhotoCraft name only to identify its source and acknowledge its authors.

## Development

The repository is evolving from its upstream codebase. Some internal package names, documentation, and build workflows may still refer to PhotoCraft while the project is being separated and renamed. Please check the existing source and build configuration before relying on upstream instructions; they may not describe EditoLina-specific changes yet.
