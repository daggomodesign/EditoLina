# EditoLina

EditoLina is a community fork of [PhotoCraft](https://github.com/storytold/photocraft), an open-source image editor made by the ArtCraft team and PhotoCraft contributors.

We’re building on their work and shaping the project in our own direction. The codebase still includes a lot of PhotoCraft, and we’ll make our changes clear as the project develops.

Thanks to everyone who built PhotoCraft and shared it under an open-source license. Their original notices and credits are kept in [`NOTICE`](NOTICE) and [`ATTRIBUTION.md`](ATTRIBUTION.md).
